# ИДЗ № 5. Повторные испытания и приближения

## Параметр варианта

Используйте выданное преподавателем целое значение $v\in\{1,\ldots,10\}$. Во всех ответах сначала укажите модель и её условия, затем вычисления и интерпретацию.

## Задача H05-P01

В $n=10+v$ независимых испытаниях $p=0{,}2$. Найдите вероятность ровно двух успехов.

## Задача H05-P02

Для той же серии найдите вероятность хотя бы одного успеха.

## Задача H05-P03

При $n=1000+10v$, $p=0{,}002$ задайте пуассоновское приближение для $P(X=0)$.

## Задача H05-P04

Для $n=200+10v$, $p=0{,}4$ стандартизуйте событие $X\le n/2$ для нормального приближения с поправкой на непрерывность.

## Задача H05-P05

На тесте из $10000v$ объектов вероятность критической ошибки $10^{-5}$. Выберите модель числа ошибок и объясните бизнес-смысл $P(X=0)$.

## Требования к сдаче

Сдать единый читаемый документ; сохранить точные выражения до округления; для вычислительного шага привести код или псевдокод и фиксированный seed; отдельно обозначить точный ответ, оценку и приближение.
