# ИДЗ № 5. Повторные независимые испытания

Источник задания: РПД, раздел 6.1, с. 18.

## Задание

Вероятность того, что наудачу взятая деталь стандартна, равна 0,85. Найдите вероятность того, что:

1. из восьми взятых деталей половина будет стандартной;
2. хотя бы одна из семи взятых деталей будет нестандартной;
3. среди 100 взятых деталей 87 будет стандартными;
4. среди 150 взятых деталей не более 125 будет стандартными.

## Что сдать

Для каждого пункта назовите точный или приближённый метод, проверьте условия его применения и сохраните достаточное число значащих цифр. Для приближений укажите стандартизацию и, если используется, поправку на непрерывность.
## Критерии оценивания РПД

- выполнено 85–100% общего объёма — «5» (отлично);
- 60–84% — «4» (хорошо);
- 40–59% — «3» (удовлетворительно);
- 0–39% — «2» (неудовлетворительно).
