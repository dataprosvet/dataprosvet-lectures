# Cheatsheet: Комбинаторика и вероятность

## Ключевые формулы

### Комбинаторика
| Что считаем | Формула | Когда |
|-------------|---------|-------|
| Перестановки | $P_n = n!$ | все элементы, порядок важен |
| Размещения | $A(n,k) = \dfrac{n!}{(n-k)!}$ | выбираем k, порядок важен |
| Сочетания | $C(n,k) = \dfrac{n!}{k!(n-k)!}$ | выбираем k, порядок не важен |
| Перест. с повтор. | $\dfrac{n!}{n_1! n_2! \dots}$ | есть одинаковые элементы |
| Разм. с повтор. | $n^k$ | выбор с возвратом |

**Правила:**
- «или» → сложение
- «и» → умножение

**Свойства сочетаний:**
$C(n,k) = C(n,n-k)$

$C(n,0)=1$

$C(n,1)=n$

### Вероятность

#### Классическая
$ P(A) = \frac{m}{n} $

**Условие:** исходы равновозможны.

#### Статистическая
$ P(A) \approx \frac{k}{N} $

k – число успехов в N испытаниях.

#### Геометрическая
$ P(A) = \frac{\text{mes}(A)}{\text{mes}(\Omega)} $

mes – длина, площадь, объём.

#### Аксиомы
1. $P(A) \ge 0$
2. $P(\Omega) = 1$
3. $P(\cup A_i) = \sum P(A_i)$ для несовместных

**Свойства:**
$0 \le P(A) \le 1$, $P(\varnothing)=0$

$P(\overline{A})=1-P(A)$

---

### Законы де Моргана
$$\overline{A \cup B} = \overline{A} \cap \overline{B}$$
$$\overline{A \cap B} = \overline{A} \cup \overline{B}$$
