# Лекция № 2. Вероятность события и её определения

## Блок 1. Аксиомы и свойства

| Элемент | Определение / формула |
|---|---|
| Вероятность | Функция $P$, сопоставляющая событию $A$ число $P(A)$. |
| Неотрицательность | $P(A)\ge0$ |
| Нормировка | $P(\Omega)=1$ |
| Счётная аддитивность | Для попарно несовместных $A_i$: $P(\bigcup_{i=1}^{\infty}A_i)=\sum_{i=1}^{\infty}P(A_i)$ |
| Невозможное событие | $P(\varnothing)=0$; обратное утверждение в непрерывной модели неверно |
| Границы | $0\le P(A)\le1$ |
| Дополнение | $P(\overline A)=1-P(A)$ |
| Монотонность | $A\subseteq B\Rightarrow P(A)\le P(B)$ |
| Разность | $P(B\setminus A)=P(B)-P(A)$ при $A\subseteq B$ |

## Блок 2. Классическая вероятность

| Элемент | Формула / условие |
|---|---|
| Определение | $P(A)=\dfrac{m}{n}=\dfrac{|A|}{|\Omega|}$ |
| $n$ / $m$ | число всех исходов / число исходов, благоприятствующих $A$ |
| Обязательные условия | $\Omega$ конечно; исходы несовместны, исчерпывают опыт и равновозможны |
| Согласованность подсчёта | числитель и знаменатель оба упорядоченные или оба неупорядоченные |

## Блок 3. Частота и статистическая вероятность

| Понятие | Формула / смысл |
|---|---|
| Абсолютная частота | $m_n$ — число наступлений события в $n$ испытаниях |
| Относительная частота | $W_n(A)=\dfrac{m_n}{n}$ |
| Статистическая вероятность | оценка неизвестной вероятности по устойчивой частоте большой серии однородных испытаний |
| Ограничение | $W_n(A)$ наблюдаема и случайна; точное равенство $W_n(A)=P(A)$ не гарантируется |

## Блок 4. Геометрическая вероятность

| Модель равномерного выбора | Формула |
|---|---|
| Отрезок | $P(A)=\dfrac{\operatorname{len}(G_A)}{\operatorname{len}(G)}$ |
| Плоская область | $P(A)=\dfrac{S(G_A)}{S(G)}$ |
| Объёмная область | $P(A)=\dfrac{V(G_A)}{V(G)}$ |

Условия: выбор равномерен относительно используемой меры; допустимая и благоприятствующая области заданы в одной модели. Вероятность одной точки при непрерывном равномерном выборе равна нулю.

## Блок 5. Выбор подхода

| Признак | Подход |
|---|---|
| Конечные обоснованно равновозможные исходы | классический |
| Равномерный выбор точки | геометрический |
| Есть серия наблюдений, теоретическая вероятность неизвестна | частотный / статистический |
| Нужна общая согласованная модель | аксиоматический |
