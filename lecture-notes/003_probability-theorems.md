# Лекция № 3. Основные теоремы теории вероятностей

## Блок 1. Сложение вероятностей

| Ситуация | Формула | Условие |
|---|---|---|
| Два любых события | $P(A\cup B)=P(A)+P(B)-P(A\cap B)$ | пересечение вычитается как дважды учтённая часть |
| Несовместные события | $P(A\cup B)=P(A)+P(B)$ | $A\cap B=\varnothing$ |
| Попарно несовместные $A_i$ | $P(\bigcup_iA_i)=\sum_iP(A_i)$ | $A_i\cap A_j=\varnothing$ при $i\ne j$ |
| Три события | $P(A\cup B\cup C)=\sum P(A_i)-\sum P(A_i\cap A_j)+P(A\cap B\cap C)$ | включения–исключения |

## Блок 2. Условная вероятность и умножение

| Понятие | Формула | Условие |
|---|---|---|
| Условная вероятность | $P(A\mid B)=\dfrac{P(A\cap B)}{P(B)}$ | $P(B)>0$ |
| Умножение | $P(A\cap B)=P(A)P(B\mid A)=P(B)P(A\mid B)$ | вероятность условия положительна |
| Цепное правило | $P(\bigcap_{i=1}^nA_i)=P(A_1)\prod_{i=2}^nP(A_i\mid A_1\cap\cdots\cap A_{i-1})$ | учитывается вся история пути |

$P(A\mid B)$ и $P(B\mid A)$ в общем случае различны.

## Блок 3. Независимость

| Вид | Критерий |
|---|---|
| Два события | $P(A\cap B)=P(A)P(B)$ |
| Эквивалентно | $P(A\mid B)=P(A)$ при $P(B)>0$ |
| Попарная независимость | критерий выполнен для каждой пары |
| Независимость в совокупности | для любого непустого $I$: $P(\bigcap_{i\in I}A_i)=\prod_{i\in I}P(A_i)$ |

Несовместность не равна независимости. Попарная независимость не гарантирует независимость в совокупности.

## Блок 4. Дерево и дополнение

| Приём | Правило |
|---|---|
| Один путь дерева | вероятности вдоль пути перемножаются |
| Альтернативные несовместные пути | вероятности путей складываются |
| Контроль узла | исходящие вероятности дают 1 |
| Хотя бы одно событие | $P(\bigcup_iA_i)=1-P(\bigcap_i\overline A_i)$ |
| Независимые события | $P(\bigcup_iA_i)=1-\prod_i(1-P(A_i))$ |
| Одинаковое $p$ | $P(\text{хотя бы одно})=1-(1-p)^n$ |
