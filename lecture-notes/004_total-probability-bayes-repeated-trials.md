# Лекция № 4. Полная вероятность, Байес и повторные испытания

## Блок 1. Гипотезы, полная вероятность и Байес

| Элемент | Формула / условие |
|---|---|
| Полная группа | $H_i\cap H_j=\varnothing$ при $i\ne j$, $\bigcup_iH_i=\Omega$, $\sum_iP(H_i)=1$ |
| Разбиение события | $A=\bigcup_i(A\cap H_i)$ — несовместные пути |
| Полная вероятность | $P(A)=\sum_iP(H_i)P(A\mid H_i)$ |
| Совместный вес | $P(H_i\cap A)=P(H_i)P(A\mid H_i)$ |
| Байес | $P(H_k\mid A)=\dfrac{P(H_k)P(A\mid H_k)}{\sum_iP(H_i)P(A\mid H_i)}$, $P(A)>0$ |
| Термины | $P(H_k)$ — априорная; $P(H_k\mid A)$ — апостериорная вероятность |

## Блок 2. Схема Бернулли

| Элемент | Формула / условие |
|---|---|
| Модель | $n$ фиксированных независимых испытаний; успех/неуспех; постоянное $p$, $q=1-p$ |
| Ровно $k$ успехов | $P_n(k)=\binom nkp^kq^{n-k}$ — **точная** формула |
| Диапазон | $P(a\le X\le b)=\sum_{k=a}^bP_n(k)$ |
| Дополнение | $P(X\ge a)=1-P(X\le a-1)$ |
| Нормировка | $\sum_{k=0}^nP_n(k)=(p+q)^n=1$ |
| Мода | $np-q\le m_0\le np+p$; если $(n+1)p\notin\mathbb Z$, $m_0=\lfloor(n+1)p\rfloor$; иначе две моды $(n+1)p-1$ и $(n+1)p$ |

## Блок 3. Приближения

| Метод | Формула | Условия |
|---|---|---|
| Пуассон | $P_n(k)\approx e^{-\lambda}\dfrac{\lambda^k}{k!}$, $\lambda=np$ | $n$ велико, $p$ мало, $np$ умеренно; **асимптотическое приближение** |
| Локальный Лаплас | $P_n(k)\approx\dfrac1{\sqrt{npq}}\varphi(x)$, $x=\dfrac{k-np}{\sqrt{npq}}$ | большие $np,nq$; одна точка |
| Интегральный Лаплас | $P(a\le X\le b)\approx\Phi(z_2)-\Phi(z_1)$ | большие $np,nq$; диапазон |
| Поправка на непрерывность | $z_1=\dfrac{a-0.5-np}{\sqrt{npq}}$, $z_2=\dfrac{b+0.5-np}{\sqrt{npq}}$ | дискретный диапазон заменяется непрерывным |

$\varphi(x)=\dfrac1{\sqrt{2\pi}}e^{-x^2/2}$, $\Phi(z)=P(Z\le z)$. Для табличной функции $L(z)=\Phi(z)-1/2$ выполняют явный перевод.

## Блок 4. Выбор метода

| Требование | Метод |
|---|---|
| Точный биномиальный ответ | Бернулли |
| Редкие события | Пуассон с проверкой качества |
| Большие $np,nq$, одна масса | локальный Лаплас |
| Большие $np,nq$, диапазон | интегральный Лаплас с поправкой |
