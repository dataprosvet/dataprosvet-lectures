## Выполненные проверки

Чистый снимок создан вне репозитория, без .venv, .runtime и кэшей Python. `docker compose build --no-cache read-api tools` заново установил закреплённые зависимости. Запуск с отдельным проектом `docker compose -p api-seminar-002-check up -d --wait` использовал новые тома. После проверки временные контейнеры, сети и тома удалены; основной комплект восстановлен.

- `docker compose run --rm --no-deps tools python -m pytest -q -p no:cacheprovider`: **20 passed**, 4 предупреждения устаревших API зависимостей, без ошибок. [Вывод](evidence/tests.log).
- `docker compose run --rm --no-deps tools python smoke.py`: **24 live checks**. Проверены реальные сервисы, документы и локальные assets, статусы 200/201/409/404/422, неизменность готового прогноза. [Вывод](evidence/http-smoke.log).
- `python validate_contract.py openapi-template.yaml contracts/read-api.json contracts/bank-offices.json contracts/office-manager.json` внутри tools: **4 документа, 36 встроенных примеров**, OpenAPI 3.1.0 и локальные ссылки. [Вывод](evidence/contracts.log).
- Chrome/Playwright: UI вернул 200 и 24 строки, офисы 43 и 999 дали разные 404; три Swagger UI отрисовали 3/5/1 операций, без JS-ошибок. Скриншот просмотрен: текст и таблица читаются.
- Реальная фоновая цепочка: Data Loader загрузил 2 наблюдения, Forecast Worker опубликовал готовый профиль, Alert Worker сохранил 63 предупреждения и отправил письма в Mailpit; повтор оставил 63 записи. Автотест также проверяет отсутствие повторной отправки в штатном повторном проходе.
- При остановленном Read API OfficeManager вернул **503 upstream_unavailable**; зависимость восстановлена. Для восстановления без повторного seed README использует `up -d --no-deps read-api`.
- Publisher: Node 20.20.2, `npm ci --ignore-scripts --no-audit --no-fund`, `npm run lint`, **122/122 tests**, локальная `npm run validate` с COURSE_BRANCH/COURSE_ROOT. Первоначально отсутствовали установленные saxes/yazl; установка по lock-файлу исправила окружение. Исходники publisher и lock-файл не изменялись. [Тесты](evidence/publisher-tests.log).
- Локальные ссылки четырёх материалов разрешаются; два новых студенческих текста проверены через git check-ignore. `git diff --check` и строгая OpenSpec-валидация успешны.

## Размеры и очистка

Рабочий образ около 170 MB, tools 191 MB, PostgreSQL 291 MB, Mailpit 40 MB. Общие слои разделяются между образами/контейнерами, поэтому сумма не равна уникальному занятому месту. Компиляторы и ML-библиотеки отсутствуют. После повторных сборок удалены старые неиспользуемые образы только проекта api-seminar-002; команда адресной очистки приведена в README. Docker build cache учитывается отдельно и глобально не очищался.

## Практические границы

Фиксированный синтетический прогноз, JSONB-снимок вместо полноценной модели хранения, последовательные writers, без авторизации, TLS и расписания. Mailpit принимает SMTP локально, внешних писем нет. Возможен повтор при сбое между SMTP и фиксацией статуса. Нулевой штат пропускается; отображение неполных данных не реализовано. Измерения этого комплекта не подтверждают SLA или полное нормативное покрытие ПР 2. Удалённая ветка seminar/02-architecture-to-http, корневой README учебного репозитория и решение публикации ПРБ/СИИ остаются вне поставки.
