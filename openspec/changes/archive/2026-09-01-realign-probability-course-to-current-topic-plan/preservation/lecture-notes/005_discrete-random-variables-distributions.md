# Лекция № 5. Дискретные случайные величины и распределения

## Блок 1. Случайная величина и ряд распределения

| Понятие | Определение / условие |
|---|---|
| Случайная величина | Числовая функция $X:\Omega\to\mathbb R$ |
| Дискретная величина | множество возможных значений конечно или счётно |
| Закон распределения | значения $x_k$ и массы $p_k=P(X=x_k)$ |
| Условия ряда | $p_k\ge0$, $\sum_kp_k=1$ |
| Вероятность события | $P(X\in B)=\sum_{x_k\in B}p_k$ |
| Многоугольник | ломаная через точки $(x_k,p_k)$; визуализирует массы, но не заменяет таблицу |

## Блок 2. Функция распределения

| Элемент | Формула / свойство |
|---|---|
| Принятая конвенция | $F_X(x)=P(X\le x)=\sum_{x_k\le x}p_k$ |
| Границы | $0\le F_X(x)\le1$, $F_X(-\infty)=0$, $F_X(+\infty)=1$ |
| Монотонность | $x_1<x_2\Rightarrow F_X(x_1)\le F_X(x_2)$ |
| Непрерывность | $F_X$ непрерывна справа |
| Масса скачка | $P(X=x_k)=F_X(x_k)-F_X(x_k-0)$ |
| Интервал | $P(a<X\le b)=F_X(b)-F_X(a)$ |
| Другие границы | $P(a\le X\le b)=F_X(b)-F_X(a-0)$; $P(a<X<b)=F_X(b-0)-F_X(a)$ |
| Конвенция источника | $F_X^{<}(x)=P(X<x)=F_X(x-0)$; перевод в принятую конвенцию выполняется явно |

## Блок 3. Именованные распределения

| Закон | Масса | Параметры и условия |
|---|---|---|
| Бернулли | $P(X=1)=p$, $P(X=0)=1-p$ | один опыт, успех/неуспех |
| Биномиальный | $P(X=k)=\binom nkp^k(1-p)^{n-k}$, $k=0,\ldots,n$ | число успехов в $n$ независимых опытах с постоянным $p$ |
| Пуассона | $P(X=k)=e^{-\lambda}\dfrac{\lambda^k}{k!}$, $k=0,1,\ldots$ | $\lambda>0$ — среднее число событий на интервале; модель потока редких событий |

## Блок 4. Проверки модели

| Проверка | Требование |
|---|---|
| Нормировка | сумма масс равна 1 |
| Границы CDF | ступени не убывают, пределы 0 и 1 |
| Биномиальная модель | фиксированное $n$, независимость, постоянное $p$ |
| Пуассоновская модель | корректно задан интервал и параметр интенсивности $\lambda$ |
| Дефект кейса 2 РПД | таблица соответствует $\operatorname{Bin}(5,0{,}1)$; подпись $p=0{,}3$ противоречива и не подменяется выдуманными данными |
