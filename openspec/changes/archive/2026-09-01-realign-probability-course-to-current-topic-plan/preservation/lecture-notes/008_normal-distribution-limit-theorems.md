# Лекция № 8. Нормальное распределение и предельные теоремы

## Блок 1. Нормальная модель

| Элемент | Формула / условие |
|---|---|
| Распределение | $X\sim N(\mu,\sigma^2)$, $\sigma>0$ |
| Плотность | $f_X(x)=\dfrac1{\sigma\sqrt{2\pi}}\exp\!\left[-\dfrac{(x-\mu)^2}{2\sigma^2}\right]$ |
| Характеристики | $E[X]=\mu$, $\operatorname{Var}(X)=\sigma^2$ |
| Стандартизация | $Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$ |
| Полная CDF | $\Phi(z)=P(Z\le z)$, $\Phi(-z)=1-\Phi(z)$ |
| Табличная функция Лапласа | $L(z)=\Phi(z)-1/2$ |
| Интервал | $P(a<X<b)=\Phi\!\left(\dfrac{b-\mu}{\sigma}\right)-\Phi\!\left(\dfrac{a-\mu}{\sigma}\right)$ — **точно** в нормальной модели |
| Симметричное отклонение | $P(|X-\mu|<\delta)=2\Phi(\delta/\sigma)-1$ |
| Правило трёх сигм | $P(|X-\mu|<3\sigma)\approx0.9973$ — численная вероятность именно нормального закона |

## Блок 2. Неравенство Чебышёва

| Форма | Формула / условие |
|---|---|
| Верхняя граница хвоста | $P(|X-E[X]|\ge\varepsilon)\le\dfrac{\operatorname{Var}(X)}{\varepsilon^2}$ |
| Нижняя граница центрального интервала | $P(|X-E[X]|<\varepsilon)\ge1-\dfrac{\operatorname{Var}(X)}{\varepsilon^2}$ |
| Условия | конечная дисперсия, $\varepsilon>0$; форма распределения не требуется |
| Тип результата | универсальная **оценка**, а не точная вероятность |

## Блок 3. Законы больших чисел

| Теорема | Условия | Результат |
|---|---|---|
| Чебышёва, общая | независимые $X_k$, $\operatorname{Var}(X_k)\le C<\infty$ | $\frac1n\sum_{k=1}^n(X_k-E[X_k])\xrightarrow{P}0$ |
| Одинаково распределённый случай | независимые одинаково распределённые, $E[X_k]=\mu$, $\operatorname{Var}(X_k)=\sigma^2<\infty$ | $\overline X_n\xrightarrow{P}\mu$ |
| Бернулли | независимые испытания с постоянной вероятностью успеха $p$ | $W_n\xrightarrow{P}p$; $P(|W_n-p|\ge\varepsilon)\le\frac{p(1-p)}{n\varepsilon^2}$ |

Сходимость по вероятности означает: для любого $\varepsilon>0$ вероятность отклонения не меньше $\varepsilon$ стремится к нулю. Она не утверждает, что отдельное наблюдение приближается к среднему.

## Блок 4. Центральная предельная теорема

| Элемент | Запись / условие |
|---|---|
| Условия базовой формы | $X_i$ независимы и одинаково распределены; $E[X_i]=\mu$; $0<\sigma^2<\infty$ |
| Стандартизованная сумма | $\dfrac{\sum_{i=1}^nX_i-n\mu}{\sigma\sqrt n}\xrightarrow{d}N(0,1)$ |
| Среднее при больших $n$ | $\overline X_n\approx N(\mu,\sigma^2/n)$ |
| Тип результата | **асимптотическое** утверждение; нормальная формула при конечном $n$ является приближением |

## Блок 5. Термины статистического вывода

| Термин | Корректная интерпретация |
|---|---|
| $H_0$ / $H_1$ | нулевая и альтернативная гипотезы |
| Уровень значимости $\alpha$ | заранее выбранная граница риска ошибки первого рода |
| p-value | вероятность при $H_0$ получить результат не менее экстремальный, чем наблюдаемый; не вероятность истинности $H_0$ |
| Решение | при малом p-value $H_0$ отвергают; иначе «нет оснований отвергнуть», а не «$H_0$ доказана» |
