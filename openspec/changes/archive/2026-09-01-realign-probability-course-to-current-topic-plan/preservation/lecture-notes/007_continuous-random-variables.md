# Лекция № 7. Непрерывные случайные величины

## Блок 1. Плотность и функция распределения

| Элемент | Формула / условие |
|---|---|
| CDF | $F_X(x)=P(X\le x)=\int_{-\infty}^{x}f_X(t)dt$ |
| Плотность | $f_X(x)=F_X'(x)$ в точках дифференцируемости |
| Неотрицательность | $f_X(x)\ge0$ |
| Нормировка | $\int_{-\infty}^{\infty}f_X(x)dx=1$ |
| Интервал | $P(a<X\le b)=F_X(b)-F_X(a)=\int_a^bf_X(x)dx$ |
| Точка | $P(X=x)=0$; тип включения конечной границы не меняет вероятность |
| Носитель | вне области возможных значений плотность равна нулю; пределы интеграла должны учитывать носитель |

Значение плотности не является вероятностью и может быть больше 1.

## Блок 2. Числовые характеристики

| Характеристика | Формула | Условие |
|---|---|---|
| Ожидание | $E[X]=\int_{-\infty}^{\infty}xf_X(x)dx$ | абсолютная сходимость |
| Функция величины | $E[g(X)]=\int_{-\infty}^{\infty}g(x)f_X(x)dx$ | интеграл существует |
| Второй момент | $E[X^2]=\int_{-\infty}^{\infty}x^2f_X(x)dx$ | конечность второго момента |
| Дисперсия | $\operatorname{Var}(X)=E[X^2]-(E[X])^2$ | конечный второй момент |
| СКО | $\sigma(X)=\sqrt{\operatorname{Var}(X)}$ | исходные единицы измерения |

## Блок 3. Равномерное распределение

| Элемент | $X\sim U(a,b)$, $a<b$ |
|---|---|
| Плотность | $f(x)=\dfrac1{b-a}$ при $a\le x\le b$, иначе 0 |
| CDF | $0$ при $x<a$; $\dfrac{x-a}{b-a}$ при $a\le x\le b$; $1$ при $x>b$ |
| Ожидание | $E[X]=\dfrac{a+b}{2}$ |
| Дисперсия | $\operatorname{Var}(X)=\dfrac{(b-a)^2}{12}$ |

## Блок 4. Показательное распределение

| Элемент | $X\sim\operatorname{Exp}(\lambda)$, $\lambda>0$ |
|---|---|
| Плотность | $f(x)=\lambda e^{-\lambda x}$ при $x\ge0$, иначе 0 |
| CDF / хвост | $F(x)=1-e^{-\lambda x}$, $P(X>t)=e^{-\lambda t}$ для $x,t\ge0$ |
| Характеристики | $E[X]=1/\lambda$, $\operatorname{Var}(X)=1/\lambda^2$, $\sigma(X)=1/\lambda$ |
| Отсутствие памяти | $P(X>s+t\mid X>s)=P(X>t)$ |
| Условие модели | постоянная интенсивность; не использовать автоматически для стареющих объектов |
