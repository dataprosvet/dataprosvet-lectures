# Карта Python-приложений

Python-блоки найдены только в восьми преподавательских сценариях. В полных студенческих лекциях, кратких конспектах и семинарах Python-fences отсутствуют, поэтому отдельные `seminar_N.py` не требуются.

| Материал | Блоков | Companion | Проверка |
|---|---:|---|---|
| лекция 1 | 2 | `attachments/lecture_1.py` | compile + execute |
| лекция 2 | 1 | `attachments/lecture_2.py` | compile + execute, SVG |
| лекция 3 | 1 | `attachments/lecture_3.py` | compile + execute |
| лекция 4 | 1 | `attachments/lecture_4.py` | compile + execute |
| лекция 5 | 1 | `attachments/lecture_5.py` | compile + execute, SVG |
| лекция 6 | 1 | `attachments/lecture_6.py` | compile + execute, SVG |
| лекция 7 | 1 | `attachments/lecture_7.py` | compile + execute, 2 SVG |
| лекция 8 | 1 | `attachments/lecture_8.py` | compile + execute, 3 SVG |

Все companion-файлы повторяют блоки материала в исходном порядке. Выполнение с `PYTHONWARNINGS=error` прошло без ошибок. В публичном плане объявлен только `lecture_1.py`, потому что только лекция 1 доступна; файлы 2–8 dormant.
