# Шаблоны приёмки

## Teacher-лекция

- [ ] Паспорт, место в курсе, пререквизиты и литература с главами.
- [ ] Отдельный блок `Компетенции по РПД`; каждый код подтверждён конкретными блоками.
- [ ] Нет раздела `Результаты обучения` и его переименованного дубля.
- [ ] Вопрос пары и таблица полного 90-минутного маршрута.
- [ ] Явные заголовки `Блок N. … (x–y минут)`.
- [ ] Внутри блоков сохранены подробный текст лектора, доска/визуализация, определения, формулы, примеры, проверки и ошибки.
- [ ] Каждое длинное доказательство содержит предпосылки, используемые результаты, промежуточные переходы и вывод; нет скрывающих шаг слов «очевидно/аналогично».
- [ ] Резюме, самостоятельная работа, переход, покрытие, источники, навигация и приложение сохранены.

## Краткий конспект

- [ ] Тематические блоки и таблицы `Понятие/определение/условия` и `Формула/обозначения/применимость`.
- [ ] Все core-определения, обозначения, формулы и типы вывода из семейной ведомости закрыты.
- [ ] Обычные примеры удалены; оставшиеся иллюстрации необходимы для границы определения.
- [ ] Нет teacher scaffolding; сохранена навигация на семинары.

## Учебный семинар

- [ ] Повторение получено из набора задач, не дублирует всю лекцию и не имеет искусственного лимита 10 минут.
- [ ] Каждый элемент повторения используется задачей; каждый метод задачи поддержан повторением.
- [ ] Есть разобранные, досочные/сопровождаемые, самостоятельные и резервные задачи; парной работы нет.
- [ ] Каждая задача содержит ровно три видимых раздела: `Условие задачи`, `Разбор решения`, `Итоговый ответ`.
- [ ] В разборе есть выбор модели, все промежуточные шаги, вычисления, проверка и интерпретация.
- [ ] Основной маршрут укладывается в 90 минут; RPD/IDZ/case и enrichment разведены.

## Контрольный семинар

- [ ] Тайминг `10/70/5/5` минут.
- [ ] Есть банк, инструкции, допустимые уточнения, сбор и границы рефлексии.
- [ ] Нет teacher-only решений; дефекты РПД не замаскированы.
