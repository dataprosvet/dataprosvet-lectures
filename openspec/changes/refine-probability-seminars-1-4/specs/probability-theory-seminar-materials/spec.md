## Purpose

Определяет сквозные правила именования семинаров и совместимость непубликуемых материалов с текущим CI курса.

## ADDED Requirements

### Requirement: Семинары 5–17 только переименовываются
Семинары 5–17 MUST получить трёхзначные kebab-case имена по своей существующей теме. Их байтовое содержимое MUST оставаться неизменным.

#### Scenario: Проверяется миграция имён
- **WHEN** старые и новые пути семинаров 5–17 сопоставляются
- **THEN** существует ровно один новый путь для каждого номера 5–17, старые пути отсутствуют, а хеш содержимого каждого файла совпадает с хешем до переименования

### Requirement: Dormant-материалы совместимы с текущим CI
Новые пути MUST оставаться внутри разрешённых корней, файлы MUST быть tracked и неисполняемыми, а изображения MUST использовать PNG, JPEG или WebP. Разрешённый корень \`lectures-teacher/\` MUST поддерживать вложенные каталоги, включая \`lectures-teacher/seminars/\`, без изменения workflow или publisher. \`course.yaml\` MUST оставаться неизменным, поэтому переименованные семинары и новые изображения остаются dormant.

#### Scenario: Преподавательские семинары находятся во вложенной папке
- **WHEN** tracked Markdown-файлы размещены по путям \`lectures-teacher/seminars/<file>.md\` и запускается текущий CI
- **THEN** вложенная папка принимается как часть разрешённого корня \`lectures-teacher/\`, сборка завершается успешно, а файлы не попадают в опубликованный набор

#### Scenario: Выполняется штатная проверка publisher
- **WHEN** запускаются lint, тесты и validate текущего publisher для ветки \`courses/probability-theory\`
- **THEN** проверка завершается успешно, новые материалы перечислены только как dormant, а публикационный digest объявленных материалов не меняется из-за dormant-ресурсов
