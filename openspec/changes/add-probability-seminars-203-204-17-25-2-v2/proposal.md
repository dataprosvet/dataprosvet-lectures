## Why

В `course.yaml` уже существуют семинары 103 и 104 другого преподавателя, поэтому материалы подгруппы 17-25-2 должны получить независимые идентификаторы и отдельные спецификации. Новые семинары 203/204 должны быть самодостаточными: каждый обязан напоминать формулы, необходимые для собственного набора задач, и поддерживать безопасное поэтапное открытие материалов.

## What Changes

- Создать семинары 203 и 204 подгруппы 17-25-2 как две самостоятельные новые capabilities со своими предметными контрактами.
- Создать для каждого семинара согласованные преподавательскую и студенческую версии с суффиксом `17-25-2`; не изменять и не использовать как источник файлы 103/104.
- В начале каждого семинара добавить рекап всех формул, необходимых для его задач, с обозначениями и условиями применимости.
- Для семинара 203 сформировать 16 задач по всем задачам 2.15–2.30 с PDF-страниц 18–19 методички 4816; условия адаптировать с сохранением хода решения, включить инфраструктурное обобщение `1-(1-0.001)^N` и публичный Python-notebook.
- Для семинара 204 сформировать полный пул из всех 17 задач, попадающих на PDF-страницы 12–18 методички Савёловой: примеры 1.4–1.8 и задачи 1.16–1.27; не включать формулы Бернулли, Пуассона и Лапласа в рекап.
- Преподавательская версия SHALL решать все задачи; студенческая SHALL раскрывать полные решения только выбранных типовых задач.
- Использовать идентификаторы `S03-01`–`S03-16` и `S04-01`–`S04-17`; типовые задачи располагать в начале, а уровни сложности показывать только преподавателю. Удалить из публичных версий раздел «Результат после обучения».
- Добавить записи 203/204 в `course.yaml` по шаблону семинара 202. Открыть только семинар 203; зарегистрировать 204 как недоступный материал без публичного Markdown или вложений.
- Не выполнять commit, push, deployment или изменение production-состояния.

## Capabilities

### New Capabilities

- `probability-theory-seminar-203-17-25-2`: содержание, формулы, задачи, инфраструктурный кейс и паритет teacher/public версий семинара 203.
- `probability-theory-seminar-204-17-25-2`: содержание, формулы, полный пул задач с PDF-страниц 12–18 методички Савёловой и паритет teacher/public версий семинара 204.

### Modified Capabilities

- `probability-theory-seminar-materials`: разрешить отдельные ресурсные записи параллельной подгруппы без изменения основной сетки и файлов 103/104.
- `probability-theory-publication-release`: зарегистрировать 203/204 как отдельные ресурсы, открыть только 203 и исключить экспонирование 204, преподавательских решений и исходных PDF.

## Impact

- Новые файлы в `lectures-teacher/seminars/`, `seminars/` и `attachments/`.
- Новые записи 203/204 в `course.yaml`; существующие записи и файлы 103/104 сохраняются побайтово.
- Потребуются математическая проверка решений и рекапов, проверка паритета задач, исполнение notebook, проверка Markdown/формул, строгая OpenSpec-валидация и контроль детерминированного плана публикации.
- Нормативный дефект, который требуется исключить: выбор без возвращения и инфраструктурные отказы нельзя считать независимыми без явного предположения.
