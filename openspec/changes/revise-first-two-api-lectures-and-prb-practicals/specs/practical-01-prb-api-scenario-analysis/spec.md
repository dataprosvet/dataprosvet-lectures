## Purpose

Defines PRB-only practical work 1 for analyzing API consumers, boundaries, data, and lifecycle stages in a business system with AI elements.

## ADDED Requirements

### Requirement: Practical work 1 is PRB-only and produces an auditable context analysis
`seminars/001_api-scenarios-and-context.md` SHALL be marked `PRB` and SHALL map only to practical work 1 of the PRB RPD. Students SHALL produce a context diagram and interface table covering consumer goal, provider, input, output, errors, interaction mode, and lifecycle stage for a business scenario involving forecasting or ERP/CRM/BI integration.

#### Scenario: Student submission is reviewed
- **WHEN** the context diagram and interface table are assessed
- **THEN** every interface has a stable identifier and direction, exposes an observable contract rather than internal tables or classes, and can be traced to the PRB task outcome

### Requirement: Practical work 1 does not claim SII scope
The material SHALL NOT present SII competencies, C++ requirements, computer-vision inference, or the SII RPD as normative for this work.

#### Scenario: Profile scope is checked
- **WHEN** headings, examples, acceptance criteria, and source mapping are scanned
- **THEN** they consistently identify `PRB` and contain no normative `SII` variant
