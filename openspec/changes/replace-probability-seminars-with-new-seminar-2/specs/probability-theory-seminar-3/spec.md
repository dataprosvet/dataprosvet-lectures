## REMOVED Requirements

### Requirement: Семинар 3 закрепляет назначенную тему
**Reason**: Владелец курса признал текущий материал семинара № 3 неактуальным и явно разрешил удалить его вместе с остальными старыми семинарами № 2–17.
**Migration**: Классическое определение вероятности переносится в новый семинар № 2; прочее покрытие должно проектироваться отдельным изменением.

#### Scenario: Старый материал семинара 3 удалён
- **WHEN** изменение применено к репозиторию
- **THEN** публичный и преподавательский файлы семинара № 3 отсутствуют, самостоятельная capability удалена при синхронизации спецификаций, а нормативное занятие не объявляется отменённым
