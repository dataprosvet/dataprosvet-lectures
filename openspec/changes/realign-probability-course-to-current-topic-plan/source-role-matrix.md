# Матрица ролей источников

## Обозначения

- **План** — `sources/лекции.pdf`, высший приоритет границ и порядка тем.
- **РПД/ОМД** — нагрузка, результаты обучения, ИДЗ, контрольные работы и оценивание.
- **Гмурман** — основная теория, формулы, доказательные переходы и базовые примеры.
- **ML-книги** — `математика для машинного обучения.pdf` и `Glubokoe_обучение...pdf`: интерпретация для данных и ML.
- **Методички** — `4816...pdf`, `Savyolova...2014.pdf`, `2_545...pdf`: упражнения и техники решения.
- **Монте-Карло** — `Savelova_Metod_Monte-Karlo_2011.pdf`: симуляция и вычислительная проверка.

Во всех публичных материалах формулировки преобразуются; локальные пути и большие цитаты не публикуются. Для каждой принятой задачи существует независимо проверенное преподавательское решение.
