## MODIFIED Requirements

### Requirement: Deliver a validated OpenAPI contract

Сдача SHALL содержать `api-design.md`, `openapi.yaml` с явно закреплённой OpenAPI 3.2.1 и примерами, состав команды, кейс, ссылку на архитектуру ДЗ 1 и GitHub pull request с итоговым commit SHA. Контракт SHALL описывать все проектируемые операции и проходить совместимую проверку структуры и ссылок; примеры SHALL соответствовать схемам. Задание SHALL давать воспроизводимую инструкцию проверки и незаполненный каркас из `attachments/seminar-002/openapi-template.yaml` без решения командного кейса.

#### Scenario: Validate a submission without a server
- **WHEN** команда сдаёт описание и OpenAPI с корректными ссылками, схемами и примерами
- **THEN** проверяющий может проверить контракт без запуска реализации; отсутствие командного сервера не является нарушением.

#### Scenario: Check the selected version and examples
- **WHEN** команда использует приложенный шаблон и указанную инструкцию проверки
- **THEN** OpenAPI 3.2.1 принимается совместимым валидатором, неправильная ссылка или пример отклоняется с понятной причиной; версия шаблона, требования задания и инструкция совпадают
