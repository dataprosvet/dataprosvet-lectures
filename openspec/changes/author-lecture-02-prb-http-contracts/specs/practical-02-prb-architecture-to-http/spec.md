## ADDED Requirements

### Requirement: The shared teaching kit supports the selected OpenAPI version
Демонстрационный комплект `attachments/seminar-002/` и его идентичная копия `lectures-teacher/seminars/seminar02-sources/` SHALL предоставлять согласованный незаполненный шаблон, инструкцию проверки и локальный Swagger UI для выбранной OpenAPI 3.2.1. Проверки SHALL различать документ/ссылки, примеры/схемы и реальный HTTP-ответ. Смена средств документации SHALL сохранять одобренную C4, состав сервисов, наблюдение трафика и бизнес-поведение моков; она MUST NOT требовать нового gRPC- или HTTP/2-сервера. Подготовка SHALL оставаться локальной и следовать первому аппруву плана лекции 2.

#### Scenario: Reuse the kit for lecture two and homework two
- **WHEN** преподаватель или команда следует локальному README обновлённого комплекта
- **THEN** документ 3.2.1 отображается, шаблон и примеры проверяются воспроизводимой командой, а действующие успешные/ошибочные сценарии семинара и обе копии комплекта сохраняются

### Requirement: Authored and generated API descriptions have explicit roles
В обеих копиях комплекта `contracts/lecture02-openapi.yaml` SHALL содержать авторский OpenAPI 3.2.1 для выбранных лекционных операций. Локальная страница `/lecture-02` SHALL показывать именно этот документ, доступный по `/lecture-02/openapi.yaml`. Существующие `/docs` и `/openapi.json` SHALL сохранять роль автоматически создаваемой документации; экспортированные `contracts/read-api.json`, `contracts/bank-offices.json` и `contracts/office-manager.json` SHALL воспроизводимо генерироваться как 3.2.1 и оставаться явно обозначенными как неполные по бизнес-схемам. Простая замена строки версии в экспортированном JSON MUST NOT выдаваться за генерацию или проверку.

#### Scenario: Inspect the document behind Swagger UI
- **WHEN** преподаватель открывает страницу лекции и сопоставляет её с YAML
- **THEN** видит тот же авторский контракт и выбранные успешный/ошибочный ответы, тогда как обычная /docs явно относится к generated-описанию и не выдаётся за полный контракт ДЗ

#### Scenario: Verify the migration from a clean local copy
- **WHEN** комплект собирается и проверяется по инструкции из чистой временной копии
- **THEN** зафиксированные инструменты принимают авторский и generated-документы 3.2.1, выбранные запросы согласуются с авторским контрактом, а неполнота generated-схем не скрывается за успешной валидацией
