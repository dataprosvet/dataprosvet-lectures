# Заметки преподавателя: практика ETL / SQL / Python

Спикер-нотов в PPTX нет. Файлы данных в `attachments/102_etl-sql-python-data.zip`: `sales.csv` и `inserts.txt`.

## Цели

Студент должен уметь:

- назвать шаги ETL и применить их к `sales.csv`
- написать SELECT / WHERE / ORDER BY / GROUP BY / HAVING
- в pandas прочитать CSV, найти пропуски и дубликаты, отфильтровать `quantity` и `price`
- посчитать `total` и выручку по категории
- сдать sql, notebook, отчёт и CSV

## Ход

1. ETL на слайдах 2–5, сразу открыть CSV.
2. SQL 6–13 на таблице из `inserts.txt` (не копировать все INSERT с доски).
3. Блок 14 — чеклист качества: NULL в `city`, нулевое количество, отрицательная цена, повторные `order_id` в конце файла.
4. pandas 15–18 — тот же Transform, что в слайдах.
5. Самостоятельная работа 19–20; разбор не заложен в слайды.

## Типичные ошибки

- Считать ETL программой, а не процессом.
- Путать WHERE и HAVING.
- Грузить CSV без проверки дублей из хвоста `inserts.txt`.
- Оставить `price < 0` или `quantity = 0` в отчёте.
