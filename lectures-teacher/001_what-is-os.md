# Заметки преподавателя: что такое ОС

Спикер-нотов в исходном PPTX нет (только номера слайдов). Ниже — акценты по содержанию слайдов, без добавленных фактов.

## Цели занятия

Студент должен уметь:

- объяснить, зачем ОС стоит между приложением и железом
- отличить user mode от kernel mode и назвать роль system call
- назвать time vs space multiplexing
- связать поколения машин с появлением batch, multiprogramming и time-sharing
- объяснить cache hit/miss, составляющие времени HDD, interrupt vs DMA vs busy waiting
- перечислить шаги загрузки и отличие hard/soft real-time

## На что давить

- Слайд про режимы: схема слоёв (hardware / OS / UI / приложения) — главный визуальный якорь.
- System call: один конкретный сюжет «прочитать файл с диска», не абстрактный список вызовов.
- История: не заучивать все модели (Honeywell, TDC-316), а смену идей: нет ОС → batch → multiprogramming/time-sharing → ПК → мобильные. Слайды 12 и 13 дублируют третье поколение.
- Hyper-threading vs многоядерность: студенты часто путают; слайд 24 уже сводит это в одну формулировку — стоит проговорить вслух.
- I/O: три способа рядом (busy waiting / interrupt / DMA), затем схемы interrupt и DMA.
- Загрузка: цепочка из шести шагов; CMOS появляется и в памяти, и в выборе boot device — связать.

## Типичные ошибки

- «Приложение само пишет на диск» — вернуть к system call и драйверу в kernel mode.
- «Hyper-threading = два ядра» — нет настоящего параллелизма на одном ядре.
- «Cache miss — ошибка программы» — это промах иерархии памяти.
- «DMA заменяет прерывания» — DMA по завершении как раз генерирует interrupt.

## Мини-квиз (слайд 55)

Имеет смысл остановиться здесь, а не в конце потока. Ответы следуют из лекции, не из внешних фактов:

1. Диск сложный и общий; нужен драйвер и ядро.
2. Kernel — полный доступ; user — ограниченный.
3. Обращение к более медленному уровню памяти.
4. CPU крутится в опросе вместо полезной работы.
5. Снять с CPU копирование больших объёмов между устройством и памятью.
6. Hard — дедлайн обязателен; soft — пропуск нежелателен, но допустим.
