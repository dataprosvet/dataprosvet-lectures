# Заметки преподавателя: понятие и источники больших данных

Спикер-нотов в PPTX нет. Ниже — акценты по слайдам, без добавленных фактов.

## Цели занятия

Студент должен уметь:

- воспроизвести определение Big Data по ГОСТ Р ИСО/МЭК 20546-2021
- отличить variety, velocity, variability, veracity
- привести примеры структурированных и неструктурированных данных
- назвать методы обработки (нейросети, Data Mining, ML) и базовые библиотеки Python
- перечислить источники данных в сельском хозяйстве
- сопоставить возможности и трудности из итоговой таблицы

## На что давить

- Определение ГОСТ — якорь всей лекции; объём упомянут в определении, остальные V — на следующем слайде.
- Форматы: не зубрить список, а критерий «ложится ли на модель данных». Письмо как пример неструктурированных.
- Поток vs пакетная загрузка в БД — граница потоковых данных.
- Источники в АПК лучше идти списком 1–7 и спрашивать, какой тип данных (машинные / поток / видео с дрона).
- Итоговая таблица слайда 16 — закрыть ею занятие; технологическая трудность «7V» в слайдах не расшифрована, не домысливать полный список V.

## Типичные ошибки

- Свести Big Data только к «много гигабайт» — в ГОСТ ещё variety, velocity, variability и масштабирование.
- Считать Excel всегда «не большими данными» — формат может быть структурированным, объём и скорость — отдельно.
- Путать velocity и variability.
