# Семинар 13. Дискретная CDF и совместные распределения

## План на 90 минут
Повторение — 16 минут; разбор — 22; доска — 20; самостоятельная работа — 22; проверка и резерв — 10 минут. Практическая подготовка встроена в задачи 2, 4 и 6.

## Теория, необходимая для задач

| Элемент | Формула / проверка | Задачи |
|---|---|---|
| CDF | $F(x)=P(X\le x)$, справа непрерывна | 1, 2 |
| Масса скачка | $P(X=x)=F(x)-F(x-0)$ | 2 |
| Маргинальные массы | $p_X(x_i)=\sum_jp_{ij}$, $p_Y(y_j)=\sum_ip_{ij}$ | 3–7 |
| Условная масса | $P(Y=y_j\mid X=x_i)=p_{ij}/p_X(x_i)$ | 4 |
| Независимость | $p_{ij}=p_X(x_i)p_Y(y_j)$ для всех ячеек | 5 |
| Cov, corr | $E[XY]-E[X]E[Y]$; $\rho=\operatorname{Cov}/(\sigma_X\sigma_Y)$ | 6, 7 |

## Задача 1 — разбор преподавателя
### Условие задачи
$P(X=0)=0{,}3$, $P(X=2)=0{,}7$. Записать $F(x)$.
### Разбор решения
$F(x)=0$ при $x<0$; $0{,}3$ при $0\le x<2$; $1$ при $x\ge2$.
### Итоговый ответ
Указанная ступенчатая функция.

## Задача 2 — разбор преподавателя
### Условие задачи
$F$ имеет скачки до $0{,}2$, $0{,}8$, $1$ в точках $-1,0,3$. Восстановить ряд.
### Разбор решения
Массы равны размерам скачков: $0{,}2$, $0{,}8-0{,}2=0{,}6$, $1-0{,}8=0{,}2$.
### Итоговый ответ
$(-1,0,3;\ 0{,}2,0{,}6,0{,}2)$.

## Задача 3 — студент у доски
### Условие задачи
Совместная таблица для $X,Y\in\{0,1\}$: $p_{00}=0{,}2,p_{01}=0{,}3,p_{10}=0{,}1,p_{11}=0{,}4$. Найти маргинальные ряды.
### Разбор решения
$P(X=0)=0{,}5$, $P(X=1)=0{,}5$; $P(Y=0)=0{,}3$, $P(Y=1)=0{,}7$.
### Итоговый ответ
$X:(0,1;0{,}5,0{,}5)$, $Y:(0,1;0{,}3,0{,}7)$.

## Задача 4 — студент у доски
### Условие задачи
Для таблицы задачи 3 найти $P(Y=1\mid X=0)$.
### Разбор решения
$p_{01}/P(X=0)=0{,}3/0{,}5=0{,}6$.
### Итоговый ответ
$0{,}6$.

## Задача 5 — самостоятельная
### Условие задачи
Независимы ли $X$ и $Y$ из задачи 3?
### Разбор решения
Уже ячейка $(0,0)$ нарушает факторизацию: $0{,}2\ne0{,}5\cdot0{,}3=0{,}15$.
### Итоговый ответ
Нет.

## Задача 6 — самостоятельная
### Условие задачи
Для таблицы задачи 3 найти $E[X]$, $E[Y]$, $E[XY]$ и Cov$(X,Y)$.
### Разбор решения
$E[X]=0{,}5$, $E[Y]=0{,}7$, $E[XY]=p_{11}=0{,}4$. Cov$=0{,}4-0{,}35=0{,}05$.
### Итоговый ответ
$0{,}5;0{,}7;0{,}4;0{,}05$.

## Задача 7 — резервная, не оценивается
### Условие задачи
Для задачи 3 найти корреляцию.
### Разбор решения
Var$(X)=0{,}25$, Var$(Y)=0{,}21$. $\rho=0{,}05/\sqrt{0{,}25\cdot0{,}21}\approx0{,}218$.
### Итоговый ответ
$\rho\approx0{,}218$.
