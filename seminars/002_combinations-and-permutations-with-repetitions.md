# Семинар № 2. Перестановки, размещения и сочетания

В публичной версии разобраны только типовые задачи. Для остальных приведены только условия.

## Задача S02-P01 [типовая]

Интерфейс задаётся выбором одной из 3 тем, одного из 4 шрифтов и одного из 2 режимов плотности. Сколько конфигураций?

**Решение.** Выборы выполняются последовательно и независимо по комбинаторному смыслу. По правилу произведения получаем $3\cdot4\cdot2=24$ конфигурации.

## Задача S02-P02

В меню доступны 5 отчётов и 3 панели мониторинга. Пользователь открывает ровно один объект. Сколько вариантов?

## Задача S02-P03

В очереди находятся 7 различных заявок. Сколькими способами можно задать порядок обработки всех заявок?

## Задача S02-P04 [типовая]

Сколько различных перестановок букв в слове «ДАННЫЕ»?

**Решение.** Всего 6 букв, буква Н повторяется дважды. Число различных перестановок равно $6!/2!=360$.

## Задача S02-P05

Из 10 моделей выбирают три и назначают им места 1, 2 и 3. Сколько рейтингов?

## Задача S02-P06

Из 12 аналитиков выбирают команду из 4 человек без распределения ролей. Сколько команд?

## Задача S02-P07 [типовая]

В команде из 4 человек должен быть хотя бы один из двух специалистов по данным; всего сотрудников 12. Сколько команд?

**Решение.** Вычтем команды без обоих специалистов: $C_{12}^4-C_{10}^4=495-210=285$.

## Задача S02-P08

Семь участников садятся за круглый стол. Повороты стола считаются одинаковыми. Сколько рассадок?

## Задача S02-P09

Сколько двоичных строк длины 10 содержат ровно три единицы?

## Задача S02-P10 [типовая]

Сколько кратчайших путей ведёт из $(0,0)$ в $(4,3)$, если разрешены шаги только вправо и вверх?

**Решение.** Любой путь состоит из 7 шагов: 4 вправо и 3 вверх. Выбираем позиции трёх вертикальных шагов: $C_7^3=35$.

## Задача S02-P11

Сколькими способами распределить 8 одинаковых задач между 3 серверами, если сервер может получить ноль задач?

## Задача S02-P12

Пароль длины 5 строится из 10 цифр без повторений и должен начинаться с нечётной цифры. Сколько паролей?

## Задача S02-P13

Найдите коэффициент при $x^2y^3z$ в $(x+y+z)^6$.

## Задача S02-P14 [типовая]

Из 20 признаков выбирают набор из 5 для полного перебора моделей. Сколько наборов признаков?

**Решение.** Порядок признаков не влияет на набор, поэтому $C_{20}^5=15504$. Это число моделей до учёта гиперпараметров.

## Задача S02-P15

Студент применил $C_8^3$ для подсчёта трёхзначных кодов из восьми символов без повторений. Найдите ошибку и исправьте ответ.
