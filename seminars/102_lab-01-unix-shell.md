## Что такое UNIX shell

Shell — текстовый пользовательский интерфейс (TUI) для доступа к сервисам операционной системы.

Разные реализации: bash, исходный Unix shell, Bourne shell, ksh, csh.

В лабораторной shell — основной инструмент работы с ОС.

## Базовые команды и справка

| Команда | Назначение |
|---|---|
| `whoami` | вывести идентификатор пользователя |
| `hostname` | показать имя хоста |
| `man [item]` | открыть руководство по команде |
| `[command] --help` или часто `-h` | краткая справка |

Из `man` выходят клавишей `q`.

```sh
whoami
hostname
man whoami
man --help
```

## Вывод содержимого и поиск

| Команда | Назначение |
|---|---|
| `less` | просмотр содержимого по одному экрану с навигацией |
| `head` | первые строки файла |
| `tail` | последние строки файла |
| `grep PATTERN [file]` | поиск PATTERN в файле или stdin |

```sh
man -h | head
man --help | tail
grep PATTERN [file]
```

## Потоки: stdin, stdout, stderr

- **stdin** — стандартный ввод программы
- **stdout** — стандартный вывод программы
- **stderr** — вывод сообщений об ошибках

Потоки можно перенаправлять в/из файлов с помощью `>` и `<`.

```sh
command > output.txt
command < input.txt
```

## Конвейеры (pipelines)

Символ `|` передаёт вывод одной программы на вход другой. Команды можно объединять в цепочки.

Пример: получить список файлов, отсортировать в обратном порядке и вывести последние 3.

```sh
ls > list.txt
head -n 3 < list.txt
ls | sort -r | tail -n 3
```

## Файловая система: основные команды

| Команда | Назначение |
|---|---|
| `pwd` | текущий рабочий каталог |
| `mkdir [dirname]` | создать каталог |
| `cd [path]` | перейти в каталог |
| `ls` | показать содержимое каталога |
| `rm [filenames]` | удалить файл |
| `rm -r [dirname]` | удалить каталог рекурсивно |
| `mv [old_path] [new_path]` | переместить файл |
| `cat [filenames]` | вывести/объединить содержимое файлов |
| `gedit [filename]` | открыть текстовый редактор GNOME |

## Специальные обозначения путей

| Обозначение | Смысл |
|---|---|
| `~` | домашний каталог пользователя |
| `.` | текущий каталог |
| `..` | родительский каталог |

Они позволяют строить короткие относительные пути.

```sh
cd ..
ls .
cd ~
```

## Как создать и переименовать файл

Создание файла: `touch [filename]`. Также: `cat ] [filename]`, `echo ] [filename]`, `gedit [filename]`.

Переименование: `mv [oldname] [newname]`.

```sh
touch example.txt
mv example.txt renamed.txt
```

## Foreground и Background

- **Foreground-процесс** блокирует shell во время выполнения.
- **Background-процесс** не блокирует shell.
- Добавление `&` запускает процесс в фоне.
- `Ctrl+Z` приостанавливает foreground-процесс.
- `bg` — продолжить в фоне; `fg` — вернуть на передний план.
- `jobs` — показать список заданий.
- Для выбора задания используется `%`: например, `fg %1`.

```sh
gedit &
# Ctrl+Z
bg
fg %1
jobs
```

## Задача 1 — каталоги и grep

- Создать каталог `week1` в домашнем каталоге.
- Перейти в `~/week1`.
- Найти в `/usr/bin` записи, содержащие “gcc”.
- Получить их в обратном алфавитном порядке.
- Сохранить результат в `~/week1/ex1.txt`.

Подсказка из материала: составить команду с `ls`, `grep`, `sort -r` и `>`.

```sh
mkdir ~/week1
cd ~/week1
ls /usr/bin | grep gcc | sort -r > ~/week1/ex1.txt
```

## Задача 3 — shell script

Создать скрипт `ex3.sh`. Скрипт должен:

1. вывести время;
2. подождать 3 секунды;
3. снова вывести время.

Использовать `date` и `sleep 3`. Запуск: `sh ex3.sh`.

```sh
date
sleep 3
date
```

```sh
sh ex3.sh
```

## Задача 4 — Hello World на C

Создать исходный файл `~/week1/main.c`. Программа печатает Hello World: `stdio.h`, `main()`, `printf()` и `return 0`.

```c
#include &lt;stdio.h&gt;
int main()
{
    printf("Hello World");
    return 0;
}
```

Скомпилировать `main.c` с помощью `gcc`. Имя исполняемого файла — `ex4`. Затем запустить `./ex4`.

```sh
gcc main.c -o ex4
./ex4
```
